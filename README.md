# mebiolsonik26 — сайт-портфолио

Статический сайт на HTML, CSS и JavaScript без сборки, без сервера и без зависимостей. Внешнее подключается только в двух случаях:
- шрифты Google Fonts;
- официальный плеер YouTube, который загружается только после нажатия Play.

## Запуск на компьютере

Самый простой способ: откройте `index.html` двойным щелчком. Всё работает и так, в том числе плеер.

Если нужен локальный сервер (чтобы было ближе к хостингу):

```
cd "МОЙ САЙТ/mebiolsonik26"
python -m http.server 8000
```

Затем откройте http://localhost:8000.

### Ссылки

В `data/site.js`, массив `links`, впишите адрес в `url`, например `"https://youtube.com/@канал"`. Пустая строка `""` означает, что кнопка не показывается. Принимаются только адреса, начинающиеся с `https://`.

### Новый проект

Добавьте в `data/projects.js` ещё один объект:

```js
{
  title: "Название",
  category: "bots",            // bots | ai | automation | web | other
  status: "В разработке",      // Работает | В разработке | Эксперимент
  description: "Пара предложений о проекте.",
  tags: ["Python", "Discord"],
  image: "assets/img/my-project.jpg",   // или "" — будет красивая заглушка
  url: "https://..."                    // или "" — кнопки не будет
}
```

Если проектов меньше трёх, сайт сам покажет блок «Новые проекты скоро».

### Новость

В `data/site.js` добавьте строку в начало `updates`: `{ date: "01.11.2026", text: "Что нового" }`.

## Музыка (NORTH MUSIC PLAYER)

Каждая позиция в `data/tracks.js` выглядит так:

```js
{
  "title": "Название",
  "artist": "Исполнитель",
  "cover": "https://i.ytimg.com/vi/ID/hqdefault.jpg",   // или путь к своей картинке, или ""
  "source_type": "youtube",          // youtube | audio | none
  "source_url": "https://www.youtube.com/watch?v=ID",
  "genre": "pop",                    // pop | rock | hiphop | electronic | unconfirmed
  "license_or_source_note": "Откуда трек и на каком основании играет"
}
```

- **YouTube.** Берите только официальное видео: канал исполнителя, VEVO или лейбла. Ссылка подойдёт в любом виде: `watch?v=`, `youtu.be/` или `shorts/`. Обложка — `https://i.ytimg.com/vi/ID/hqdefault.jpg`, где ID — 11 символов из ссылки.
- **Свой файл.** Положите mp3 в `audio/` и укажите `"source_type": "audio"` и `"source_url": "audio/файл.mp3"`. Так можно делать **только** с музыкой, на которую у вас есть право: своей, по свободной лицензии, по разрешению автора. Громкость и перемотка работают через HTML Audio.
- **`none`** означает пустую позицию: она видна в списке, но кнопка Play неактивна.

### Ограничения плеера YouTube

- Видео показывается в самом плеере: правила YouTube запрещают прятать плеер и играть «только звук».
- Владелец видео может запретить встраивание (ошибки 101/150). Тогда плеер пишет об этом, даёт ссылку на YouTube и переходит к следующему треку.
- На iPhone и iPad громкость меняется только кнопками телефона. Это ограничение iOS, а не сайта.
- Сам по себе звук не включается: всё стартует только по нажатию. Первый запуск на телефоне иногда требует ещё одного касания по видео — так устроены мобильные браузеры.
- Используется домен `youtube-nocookie.com` (режим повышенной конфиденциальности). Сам скрипт YouTube подгружается только после первого Play. Обложки берутся с `i.ytimg.com`.

Бесплатно публикуются только **публичные** репозитории. Лимиты: сайт до 1 ГБ, мягкий лимит трафика 100 ГБ в месяц.

Адрес: **https://legusiano.github.io/mebiolsonik26/**

Адрес `mebiolsonik26.github.io` возможен только у аккаунта GitHub с именем `mebiolsonik26`. Если когда-нибудь заведёте такой аккаунт, перенесите туда репозиторий под именем `mebiolsonik26.github.io`. В `404.html` и метатегах `index.html` тогда поменяйте пути `/mebiolsonik26/` на `/`.

Альтернативы на будущее:
- **Cloudflare Pages** — адрес `mebiolsonik26.pages.dev`, если имя свободно; нужен аккаунт Cloudflare.
- **Vercel** — `mebiolsonik26.vercel.app`; нужен аккаунт.

Сайту не нужна никакая настройка: подойдёт любой статический хостинг.

Как обновить:

```

git add -A
git commit -m "Обновил проекты"

```

## Безопасность

- В коде нет ключей, токенов и паролей, и добавлять их сюда нельзя: всё, что лежит в репозитории, видно всем.
- Нет трекеров, аналитики и рекламных скриптов. Реклама — это только ваши собственные блоки из `window.ADS`.
- Старый файл `МОЙ САЙТ/inde.html` в этот сайт не входит. В нём вшиты чужие MP3, поэтому публиковать его нельзя.
