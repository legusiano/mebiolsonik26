# mebioslonik26 — сайт-портфолио

Статический сайт на HTML, CSS и JavaScript без сборки, без сервера и без зависимостей. Внешнее подключается только в двух случаях:
- шрифты Google Fonts;
- музыкальные отрывки и обложки из каталога Apple (iTunes).

## Запуск на компьютере

Самый простой способ: откройте `index.html` двойным щелчком. Всё работает и так, в том числе плеер.

Если нужен локальный сервер (чтобы было ближе к хостингу):

```
cd "МОЙ САЙТ/mebiolsonik26"
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Где что менять

| Что | Файл |
|---|---|
| Заголовок, текст главного экрана, «Обо мне», услуги, контакты, ссылки, «Что я изучаю», новости | `data/site.js` |

| Свои аудиофайлы | папка `audio/` |

После правки сохраните файл и обновите страницу. На хостинге изменения появятся после `git push`, обычно через одну–две минуты.

### Ссылки

В `data/site.js`, массив `links`, впишите адрес в `url`, например `"https://youtube.com/@канал"`. Пустая строка `""` означает, что кнопка не показывается. Принимаются только адреса, начинающиеся с `https://`.

### Новый проект

Добавьте в `data/projects.js` ещё один объект:

```js
{
  title: "Название",
  category: "bots",            // bots | ai | automation | web | other
  status: "В разработке",      // Работает | В разработке | Эксперимент
  description: "Пара предложений о проекте.",
  tags: ["Python", "Discord"],
  image: "assets/img/my-project.jpg",   // или "" — будет красивая заглушка
  url: "https://..."                    // или "" — кнопки не будет
}
```

Если проектов меньше трёх, сайт сам покажет блок «Новые проекты скоро».

### Новость

В `data/site.js` добавьте строку в начало `updates`: `{ date: "01.11.2026", text: "Что нового" }`.

## Музыка (NORTH MUSIC PLAYER)

YouTube не используется. Играют **официальные 30-секундные отрывки из каталога Apple**: их отдаёт открытый iTunes Search API. Сайт показывает обложку и даёт ссылку «полностью» на Apple Music. Целые песни популярных исполнителей нельзя размещать на сайте без лицензии, поэтому здесь только отрывки.

Всё работает через HTML Audio:
- воспроизведение и пауза;
- переключение треков;
- перемешивание;
- перемотка;
- время;
- громкость и выключение звука;
- избранное, поиск и фильтры;
- мини-плеер внизу экрана, когда основной не виден;
- управление с клавиатуры телефона или наушников (Media Session).

Сейчас 58 треков. Все отрывки и обложки проверены 24.10.2026: ссылки отвечают.
- **Weezer**: Buddy Holly, Across the Sea, Island in the Sun, Say It Ain't So и другие. «Визари», «акровс сеа» и «боди хол» оказались Weezer, Across the Sea и Buddy Holly.
- **Поп-панк, альтернатива и инди**: Pixies, Foo Fighters, Green Day, blink-182, Nirvana, Arctic Monkeys, The Killers и другие.
- **Тренды TikTok**: отмечены значком TT и вынесены в отдельный фильтр.
- **Русское**: Би-2, Кино, Король и Шут, Сплин, ДДТ, Земфира, Пошлая Молли и другие.

Запись в `data/tracks.js`:

```js
{
  "title": "Buddy Holly",
  "artist": "Weezer",
  "album": "Blue / Green / Red",
  "cover": "https://is1-ssl.mzstatic.com/.../600x600bb.jpg",
  "source_type": "preview",          // preview — отрывок из iTunes; audio — свой файл (играет целиком)
  "source_url": "https://audio-ssl.itunes.apple.com/...m4a",
  "full_url": "https://music.apple.com/...",
  "genre": "weezer",                 // weezer | punk | alt | indie | ru
  "tiktok": true,
  "explicit": false,
  "license_or_source_note": "Откуда трек"
}
```

**Как добавить трек.** Откройте в браузере `https://itunes.apple.com/search?term=Weezer+Buddy+Holly&entity=song&limit=5` и возьмите из ответа три поля:
- `previewUrl` → `source_url`;
- `artworkUrl100` → `cover` (замените `100x100bb` на `600x600bb`);
- `trackViewUrl` → `full_url`.

Проще — напишите мне название трека.

**Свой трек целиком.** Положите файл в папку `audio/` и укажите `"source_type": "audio"`, `"source_url": "audio/файл.mp3"`. Только для музыки, на которую у вас есть права.

## Защита

Полностью защитить статический сайт нельзя: всё, что показывает браузер, можно сохранить. Код к тому же лежит в публичном репозитории — бесплатный GitHub Pages работает только так. Поэтому стоит базовая защита, которая отсекает случайное и ленивое копирование:
- нельзя выделить текст, вызвать меню правой кнопкой или перетащить картинки;
- сочетания клавиш Ctrl+S / U / P / Shift+I и F12 перехватываются;
- к скопированному тексту автоматически добавляется подпись со ссылкой на оригинал;
- если сайт скопируют на чужой домен, сверху появится плашка «Это копия. Оригинал: …»;
- Content-Security-Policy: страница загружает скрипты только со своего адреса, а внешнее — только шрифты Google и музыку и обложки Apple;
- в репозитории лежит файл `LICENSE` («все права защищены»), а в подвале — ©.

Чтобы спрятать и сам код, нужен приватный репозиторий с платным GitHub Pro или другой хостинг, например Cloudflare Pages из приватного репозитория. Это можно сделать позже.

## Публикация (GitHub Pages, бесплатно, HTTPS)

Выбран GitHub Pages:
- сайт статический, сборка не нужна;
- аккаунт GitHub уже есть;
- HTTPS включается автоматически;
- обновление — обычный `git push`.

Бесплатно публикуются только **публичные** репозитории. Лимиты: сайт до 1 ГБ, мягкий лимит трафика 100 ГБ в месяц.

Адрес: **https://legusiano.github.io/mebiolsonik26/**

Адрес `mebiolsonik26.github.io` возможен только у аккаунта GitHub с именем `mebioslonik26`. Если когда-нибудь заведёте такой аккаунт, перенесите туда репозиторий под именем `mebiolsonik26.github.io`. В `404.html` и метатегах `index.html` тогда поменяйте пути `/mebiolsonik26/` на `/`.

Альтернативы на будущее:
- **Cloudflare Pages** — адрес `mebioslonik26.pages.dev`, если имя свободно; нужен аккаунт Cloudflare.
- **Vercel** — `mebioslonik26.vercel.app`; нужен аккаунт.

Сайту не нужна никакая настройка: подойдёт любой статический хостинг.

Как обновить:

```
cd "МОЙ САЙТ/mebiolsonik26"
git add -A
git commit -m "Обновил проекты"
git push
```

## Безопасность

- В коде нет ключей, токенов и паролей, и добавлять их сюда нельзя: всё, что лежит в репозитории, видно всем.
- Нет трекеров, аналитики и рекламных скриптов. Реклама — это только ваши собственные блоки из `window.ADS`.
- Старый файл `МОЙ САЙТ/inde.html` в этот сайт не входит. В нём вшиты чужие MP3, поэтому публиковать его нельзя.
