# Исследование проекта Лани для презентации (24.10.2026)

Источник — исходники репозитория `legusiano/lani_bot` (приватный). Значения `.env`, логи и пользовательские данные не использовались.

## Что посчитано по коду
- 31 модуль Python, ≈ 11 600 строк (`*.py` в корне).
- 95 slash-команд — собраны автоматически из декораторов `@tree.command` / `@group.command` (см. `commands.js`).
- 20 фраз, которые Лани понимает в чате и голосом — из `quick.py`, `voice_cmds.py`, `style.py`.
- Тесты: 22 файла, **564 passed, 1 skipped** (запуск `.venv/Scripts/python -m pytest -q` 24.10.2026).

## Архитектура (подтверждено)
- `bot.py` на Render (через `lani_runner.py` в репозитории dz_bot): чат, ИИ, игры, музыка, автомодерация, ранги, напоминания, контент дня, `/owner`.
- `voice.py` на ПК владельца: Vosk (`vosk-model-small-ru-0.22`) ловит имя, faster-whisper уточняет фразу, edge-tts озвучивает (EdgePool держит тёплые соединения), Fish Audio — если есть ключ, голос Windows — без интернета.
- База — Neon Postgres (таблица `state` ключ-значение + таблицы памяти/напоминаний в `store.py`).
- ИИ — DeepSeek `deepseek-flash`, запасной — Gemini; общий клиент `aicore.py` (тайм-аут 30 с, 4 запроса разом, статистика), предохранитель `aicore.Breaker`.
- Сторож — `dz_bot/watchdog.py` в GitHub Actions раз в 30 минут.

## Замеры
- Первый токен ИИ в голосе без «размышлений»: 0,75–0,94 с против 1,05–1,83 с с ними (замер 23.10.2026, комментарий в `voice.py`). Других замеров скорости нет — общая задержка копится в `/owner diagnostics`.
