# LANI — презентация

- **Онлайн:** https://legusiano.github.io/mebiolsonik26/lani/
- **Локально:** из папки сайта `python -m http.server 8000` → http://localhost:8000/lani/ (можно и открыть `index.html` двойным щелчком).

## Управление
- `→` / пробел / `PageDown` — дальше, `←` / `PageUp` — назад, `Home` / `End` — первый и последний слайд;
- поле с номером внизу — перейти к слайду; адрес `…/lani/#9` открывает сразу 9-й слайд;
- `F` или кнопка ⛶ — полный экран; «☰ Разделы» — меню всех слайдов;
- «✦ анимации» — выключить движение (системная настройка «уменьшить движение» учитывается сама);
- на телефоне — свайпы влево и вправо.

## Файлы
- `index.html`, `styles.css`, `app.js` — сама презентация (без библиотек);
- `commands.js` — каталог команд, собранный из исходников Лани;
- `LANI_Presentation.pdf`, `LANI_Presentation.pptx` — 28 слайдов картинками (интерактивный каталог — только в браузере);
- `presentation_research.md` — откуда взяты факты.

## Как пересобрать PDF и PPTX
Снимки слайдов: `chrome --headless=new --window-size=1600,900 --screenshot=sNN.png "http://127.0.0.1:8000/lani/?still&export#NN"`
(`?still` — без анимаций, `?export` — без кнопок), затем PDF через Pillow и PPTX через python-pptx.
